# 随机密码生成器 🔐

密码学安全的 Windows 密码生成工具 - 绿色单文件版本

## 功能特性

### 核心功能
- ✅ **密码学安全随机数生成**：使用 Python `secrets` 模块（CSPRNG）
- ✅ **可调节长度**：4-64 字符，默认 16 位
- ✅ **灵活字符集**：大写字母、小写字母、数字、特殊符号
- ✅ **排除易混淆字符**：可选过滤 `0 O I l 1`
- ✅ **实时强度指示**：可视化密码强度评估

### 安全特性
- 🔒 **剪贴板自动清空**：20 秒后自动清除（可选）
- 🔒 **手动立即清空**：一键清除剪贴板
- 🔒 **排除 Windows 剪贴板历史**：使用 Windows API 阻止密码进入 Win+V 历史（Windows 10 1809+）
- 🔒 **阻止云同步**：防止密码同步到其他设备
- 🔒 **程序关闭时自动清理**：清空剪贴板 + 覆盖内存
- 🔒 **无文件留痕**：不保存任何历史记录

## 使用方法

### 方式一：直接运行（需要 Python 环境）

1. 确保已安装 Python 3.8+
2. 安装依赖：
   ```bash
   pip install PyQt6 Pillow
   ```
3. 运行程序：
   ```bash
   python password_generator.py
   ```

### 方式二：打包成 .exe（推荐）

1. 在 Windows 上执行：
   ```cmd
   build_exe.bat
   ```
2. 等待打包完成（约 1-2 分钟）
3. 在 `dist` 文件夹找到 `密码生成器.exe`
4. 双击运行，无需安装

## 安全说明

### 随机性保证
- ✅ 使用 `secrets.choice()` - Python 标准库的密码学安全伪随机数生成器（CSPRNG）
- ✅ 等同于 Windows 的 `BCryptGenRandom` / Linux 的 `/dev/urandom`
- ✅ 满足现代密码学安全标准（Bitcoin、TLS、SSH 同级别）

### 剪贴板安全
Windows 剪贴板是全局共享区域，任何程序都可以读取。本工具采取以下措施降低风险：

1. **真正排除历史记录**：直接调用 Windows API，设置 `ExcludeClipboardContentFromMonitorProcessing` 和 `CanIncludeInClipboardHistory` 标记，密码**不会**进入 Win+V 剪贴板历史
2. **阻止云同步**：同样的 API 调用也会阻止密码同步到 OneDrive 或其他设备
3. **限时留存**：20 秒后自动清空（仅当内容未被覆盖时）
4. **手动清空**：提供立即清空按钮
5. **关闭清理**：程序退出时自动清空剪贴板 + 覆盖内存

✅ **Windows 10 1809（2018年10月更新）及以上版本**：API 生效，真正阻止历史  
⚠️ **更早版本的 Windows**：降级到普通复制，建议手动关闭剪贴板历史功能

⚠️ **残酷现实**：只要密码进入剪贴板，在粘贴的几秒内理论上可被其他程序读取。这是 Windows 架构限制，无法 100% 杜绝。我们只能最小化风险窗口。

### 为什么不是"真随机"？
- **密码学安全的伪随机（CSPRNG）已足够安全**，NSA 级别攻击也无法预测
- 硬件真随机（TRNG）理论上更好，但对密码生成来说提升微乎其微
- 被破解的硬件钱包使用的是**垃圾伪随机**（如 `rand()` + 时间戳），不是 CSPRNG

## 常见问题

**Q: 为什么 .exe 文件这么大？**  
A: PyInstaller 打包时会包含整个 Python 解释器和 PyQt6 库。这是绿色单文件的代价。

**Q: 杀毒软件报毒怎么办？**  
A: PyInstaller 打包的程序常被误报。可以：
   1. 添加到白名单
   2. 直接运行 .py 源码
   3. 使用代码签名证书（需购买）

**Q: 可以在 Mac/Linux 上用吗？**  
A: 可以直接运行 .py 源码，但打包脚本需要改写（使用 PyInstaller 的 Linux/macOS 语法）。

**Q: 密码强度指示准确吗？**  
A: 基于长度和字符多样性的简单评估，仅供参考。真正的强度取决于熵值和使用场景。
